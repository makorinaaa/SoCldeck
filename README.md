# SocialDeck 🦜

TweetDeck風のマルチカラムSNSクライアント。  
**X (Twitter)** を WebView でそのまま表示、**Bluesky** は AT Protocol API でリアルタイム取得。

---

### 情報カラム

- **本日のアニメ**: 「カラム追加」→「情報」から追加できます。AniListの放送・配信予定を日本時間の当日0:00から翌日3:00（27:00）まで取得し、日本制作のTV・短編・オンライン配信作品を時刻順に表示します。

## 🚀 セットアップ

### 必要なもの
- [Node.js](https://nodejs.org/) v22以上
- npm

### インストール・起動

```bash
# このフォルダに移動
cd socialdeck

# 依存パッケージをインストール
npm install

# 起動
npm start

# 開発モード（DevTools付き）
npm run dev
```

### ビルド（配布用）

```bash
# Windows インストーラー (.exe)
npm run build-win

# Mac (.dmg)
npm run build-mac

# Linux (.AppImage)
npm run build-linux
```

ビルド成果物は `dist/` フォルダに生成されます。

### テスト・リリース確認

```bash
# ユニットテストとElectron E2E
npm run test:all

# テスト後にWindows unpackedビルドまで確認
npm run release:check

# テスト後にWindowsインストーラーを作成
npm run release:win
```

詳細な公開手順は [RELEASE.md](RELEASE.md) を参照してください。

カラム操作の変更先とモジュールの役割は [Renderer の変更ガイド](docs/renderer-maintenance.md) を参照してください。

## 📖 使い方

### ログイン

1. 起動するとログイン画面が表示されます
2. **X タブ**: 表示名（@username）を入力して「X カラムを追加」
   - X は WebView 表示のため、初回はブラウザと同様に X.com でログインしてください
3. **Bluesky タブ**: ハンドルとアプリパスワードを入力
   - アプリパスワード: [bsky.app/settings/app-passwords](https://bsky.app/settings/app-passwords) で発行
4. 「開く →」でアプリを起動

### カラム操作

- **追加**: 左サイドバーの「＋」またはトップバー「カラム追加」
- **更新**: カラムヘッダーの更新ボタン、またはサイドバーの「↻」（全更新）
- **設定・削除**: カラムヘッダーの「…」メニュー
- **更新失敗**: カラム内の原因表示と「再試行」ボタンから復旧できます
- **もっと見る**: Bluesky カラムの最下部ボタン

### キーボードショートカット

| キー | 動作 |
|------|------|
| `Ctrl+N` | カラムを追加 |
| `Ctrl+R` | すべて更新 |
| `Ctrl+←` | 左にスクロール |
| `Ctrl+→` | 右にスクロール |
| `Esc` | モーダルを閉じる |

### 投稿

- サイドバーのX・Bluesky投稿ボタンから投稿モーダルを開けます
- 「Xにも投稿」「Blueskyにも投稿」を選ぶと両サービスへ同時投稿できます（返信を除く）
- 投稿プレビュー、画像ALT、`Ctrl+Enter`による送信に対応しています
- 本文と返信先をアカウントごとに自動保存し、閉じても再起動しても復元します。「下書きを削除」で破棄できます
- 添付ファイルはアプリ起動中のみ保持します。再起動後は投稿画面の案内に従って選び直してください
- 同時投稿は投稿先ごとの結果を表示し、成功済みの投稿先を除いて再試行します。結果不明の場合は投稿先で確認してから再試行してください

### 設定・表示密度

- サイドバーの「設定」から、外観・通知・ミュート・メモリ管理・アカウント設定を開けます
- 「外観・表示密度」でコンパクト／標準／ゆったりを選ぶと、文字・行間・余白・ボタンのサイズをプレビューできます。「保存」で適用、「キャンセル」で元に戻します
- Xの埋め込み画面の本文サイズは、カラムの「…」→「カラム設定」から調整します

### デスクトップ通知

- サイドバーの「設定」→「デスクトップ通知」から有効化できます
- X / Bluesky、返信・メンション・引用・フォロー・いいね・リポストを個別に選択できます
- 特定ユーザー、キーワード、「SocialDeckを操作していない時だけ」で絞り込めます
- 初回有効化時は現在の通知を基準として記録し、過去通知をまとめて表示しません
- 通知をクリックするとSocialDeckが前面に戻り、対象の投稿またはプロフィールを開きます

### バックアップ・復元と削除取り消し

- 「設定」→「バックアップと復元」から JSON ファイルの書き出し・読み込みができます。対象は外観、カラム配置・幅・折りたたみ・更新間隔・文字サイズ、ミュート、同時投稿、デスクトップ通知、メモリ管理の設定です。
- 認証情報、下書き、添付ファイル、通知履歴は含みません。別の環境で復元するときは、同じ X / Bluesky アカウントを先に追加してください。X は表示名で照合するため、重複する表示名は区別できる名前に変更してください。
- ファイルを選ぶと復元内容を表示します。「この内容で復元して再読み込み」で適用します。添付ファイルは再選択が必要です。送信中は復元できません。
- 復元直前の状態を自動退避します。「前回の復元直前に戻す」で戻せます。通常のアカウント設定・レイアウト保存も直前の正常な値を保持し、読み込めないデータは退避して復旧結果を画面で知らせます。
- カラムを削除すると画面左下に「元に戻す」が表示されます。直前の1件を、元の位置と設定で復元できます。取り消しはアプリ起動中のみ有効です。
- PR と main への push でユニットテストと Electron E2E を別ジョブで実行します。E2E ログは CI の成果物に7日間保存します。

## 🔐 セキュリティ

- Bluesky のセッショントークンは Electron の `safeStorage` で暗号化して保存します。アプリパスワードはログインに使用し、保存しません
- X のセッションは Electron の永続パーティション (`persist:x`) に保存されます
- アプリパスワードはBlueskyの認証APIにのみ送信されます
- OSアカウントを共有する端末では、第三者がアプリデータを閲覧できないよう注意してください

- **WebView2 (webview タグ)** — X.com をそのまま表示

## ⚠️ 注意事項

- X の表示は公式サイトをそのまま埋め込んでいます。X の仕様変更により動作しなくなる可能性があります
- 本アプリは個人利用を想定した非公式クライアントです

### v2.5.0 の自動更新（Windows）

GitHub Releases のインストーラーで導入したアプリは、起動10秒後と4時間ごとに更新を確認し、自動ダウンロードします。更新通知から再起動するか、アプリ終了時に適用されます。ソースからの開発起動は自動更新の対象外です。
