# SocialDeck 🦜

X と Bluesky を1つの画面で並べて使える、TweetDeck 風のマルチカラムクライアントです。

- **X** は公式サイトをアプリ内にそのまま表示します（複数アカウント対応）
- **Bluesky** は公式 API で取得し、アプリ独自の画面で表示します
- 両方への同時投稿、通知のまとめ表示、デスクトップ通知に対応しています

> 個人利用を想定した非公式クライアントです。X の表示は公式サイトの埋め込みのため、X 側の仕様変更で動かなくなることがあります。

---

## 📥 インストール

[GitHub Releases](https://github.com/makorinaaa/SoCldeck/releases) から Windows 用インストーラー（`SocialDeck-<バージョン>-x64.exe`）をダウンロードして実行します。

インストーラーで入れたアプリは自動で更新されます。起動10秒後と、その後4時間ごとに新しいバージョンを確認してダウンロードし、通知から再起動するか、アプリの終了時に適用します。

## 📖 使い方

### はじめに：アカウントを追加する

起動するとログイン画面が開きます。

- **X**：表示名（任意・アカウントを見分けるための名前）を入れて「Xアカウントを追加」を押し、表示された X の画面でログインします
- **Bluesky**：ハンドルと**アプリパスワード**を入れて「Bluesky でログイン」を押します。アプリパスワードは [bsky.app の設定](https://bsky.app/settings/app-passwords) で発行できます（普段のパスワードは使いません）

追加したら「開く →」でメイン画面へ進みます。アカウントは後から「設定」→「アカウント」で追加・ログアウトできます。

### カラム

画面は「カラム」を横に並べて使います。サイドバーの「＋」やメニューの「カラムを追加」から追加します。

| サービス | 追加できるカラム |
|---|---|
| X | ホーム、通知、検索、リスト、設定 |
| Bluesky | タイムライン、通知、検索、Discover フィード、プロフィール、投稿ページ、設定 |
| 情報 | 本日のアニメ（AniList の放送・配信予定を日本時間 0:00〜27:00 で表示） |

- カラムはドラッグで並べ替え、端をドラッグで幅を変更、折りたたみもできます
- ヘッダーの「⋯」から、更新間隔・文字サイズの変更や削除ができます
- 削除しても、画面左下の「元に戻す」で直前の1件を元の位置に戻せます（アプリ起動中のみ）
- 更新に失敗したカラムには原因と「再試行」ボタンが表示されます

### 投稿

サイドバーの X / Bluesky の投稿ボタンから投稿画面を開きます。

- 画像（最大4枚・ALT 付き）または動画1本を添付できます。動画は投稿前にトリミングできます
- 「Xにも投稿」「Blueskyにも投稿」で両方へ同時に投稿できます（返信を除く）。再試行では、成功した投稿先を除いて送り直します
- 書きかけの本文と返信先はアカウントごとに自動保存され、再起動しても戻ります。添付ファイルは保存されないので、再起動後は選び直してください
- `Ctrl+Enter` で送信、プレビューで投稿前の見た目を確認できます

### 通知

- **通知センター**：X と Bluesky の通知をまとめて表示します。サービス・種類・未読・会話（返信・メンション・引用）で絞り込めます
- **デスクトップ通知**：「設定」→「デスクトップ通知」で有効にします。サービス、通知の種類、特定のユーザー・キーワード、「SocialDeck を操作していない時だけ」で絞り込めます。クリックすると対象の投稿やプロフィールを開きます。有効にした時点より前の通知はまとめて表示しません

### キーボードショートカット

`?` を押すと、アプリ内でも一覧を表示できます。

| キー | 動作 |
|---|---|
| `j` / `k` | 次 / 前の投稿へ移動 |
| `←` / `→` | 隣のカラムへ移動（投稿を選択中） |
| `1`〜`9` | N 番目のカラムへ移動 |
| `l` / `t` / `r` | いいね / リポスト / 返信（Bluesky） |
| `o` / `Enter` | 投稿を開く |
| `n` | 新規投稿（選択中のカラムのサービスで） |
| `Esc` | 選択を解除・画面を閉じる |
| `Ctrl+N` | カラムを追加 |
| `Ctrl+R` | すべて更新 |
| `Ctrl+Enter` | 投稿を送信 |

1文字のショートカットは、文字の入力中や設定画面などを開いている間は反応しません。X のカラムを選択している間は、X 自体のショートカットが使えます。

### 設定

サイドバーの「設定」から開きます。

- **外観・表示密度**：テーマ、アクセントカラー、表示密度（コンパクト／標準／ゆったり）。保存前にプレビューできます
- **ミュート**：表示しないキーワードとユーザー
- **メモリ管理**：使用量の確認と自動整理
- **バックアップと復元**：カラム配置や各種設定を JSON ファイルに書き出し・読み込みできます。ログイン情報・下書き・添付ファイル・通知履歴は含まれません。別の PC で復元するときは、先に同じアカウントを追加してください（X は表示名で照合します）。復元直前の状態は自動で退避され、「前回の復元直前に戻す」で戻せます

メニューからは、画面の拡大・縮小、全画面表示、**デスクトップウィジェット**（1つのカラムを透過・最前面で表示）も使えます。

## 🔐 セキュリティとプライバシー

- **Bluesky**：アプリパスワードはログインにだけ使い、保存しません。ログイン後のセッション情報は OS の暗号化機能（Electron `safeStorage`）で暗号化して保存します
- **X**：ログイン状態はアカウントごとに分けて保存し、Cookie は OS の暗号化キーで暗号化します。X の認証 Cookie の中身はアプリの画面側には渡しません
- **ログアウト**：X のアカウントを削除すると、そのアカウントの Cookie・保存データ・キャッシュを消去します
- **アプリの保護**：画面とシステムを分離（`contextIsolation`・`sandbox`）し、アプリ内部の操作は自アプリの画面からの要求だけを受け付けます

暗号化は「他の PC にデータを持ち出されても読めない」ための仕組みです。同じ OS アカウントにログインしている人や、そのアカウントで動くマルウェアからは保護できません。PC を共有する場合は OS のアカウントを分けてください。

詳しい方針は [SECURITY.md](SECURITY.md) を参照してください。

## 🛠️ 開発者向け

### 準備と起動

[Node.js](https://nodejs.org/) v22 以上が必要です。動作確認と CI は Windows で行っています。

```bash
npm install
```

```bash
npm start
```

`npm run dev` で開発者ツール付きで起動します。どちらも起動前に、動画処理用の FFmpeg を自動で取得・検証します（Windows）。

### テスト

| コマンド | 内容 |
|---|---|
| `npm run lint` | ESLint による静的チェック |
| `npm test` | 単体テスト |
| `npm run test:e2e` | 隔離した Electron 環境での画面操作テスト |
| `npm run test:all` | 単体テスト + E2E |
| `npm run test:security` | ローカルの疑似サーバーを使ったセキュリティテスト |
| `npm run security:check` | 秘密情報の混入チェック |

PR と main への push では、GitHub Actions で lint・単体テスト・E2E・セキュリティテストを実行します。

### ビルドとリリース

```bash
npm run build-win
```

成果物は `dist/` に作られます。`build-mac` / `build-linux` もありますが、CI では検証していません。リリース手順は [RELEASE.md](RELEASE.md) を参照してください。
