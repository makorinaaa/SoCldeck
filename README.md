# SocialDeck 🦜

X と Bluesky を1つの画面で並べて使える、TweetDeck 風のマルチカラムクライアントです。

- **X** は公式サイトをアプリ内にそのまま表示します（複数アカウント対応）。「X の自動化機能」を使う設定にすると、ホーム・リスト・通知を Bluesky と同じアプリ独自の画面でも読めます（下の注意を参照）
- **Bluesky** は公式 API で取得し、アプリ独自の画面で表示します
- 両方への同時投稿、通知のまとめ表示、デスクトップ通知に対応しています（X 側は「X の自動化機能」を使う設定のときのみ）

> [!WARNING]
> **X 連携の自動化機能は、X の規約に反する可能性があります。使うと、X のアカウントが制限されたり永久凍結されたりする可能性があります。**
>
> 次の機能は、X の API を使わず、画面外で開いた X のページのデータを読み取ったり、X のページのボタンをスクリプトで押したりして動いています。
>
> - ネイティブ版のホーム・リスト・通知カラム
> - SocialDeck の投稿画面からの X への投稿・返信・同時投稿
> - 通知センターとデスクトップ通知の X の通知
> - X カラムの自動更新
>
> X は、API 以外の自動化（ウェブサイトをスクリプトで操作するなど）と、許可のないスクレイピングを禁止しています（[自動化ルール](https://help.x.com/en/rules-and-policies/x-automation)・[利用規約](https://x.com/en/tos)）。「API を直接呼ばない」ことは、規約に従っていることを意味しません。
>
> X がアカウントのロック・本人確認の画面を出したり、回数制限（429）を返したり、投稿時に上限・制限を表示したりしたときは、そのアカウントの X の操作（自動更新・読み取り・ボタン操作・投稿）を自動で止めます。再起動しても止めたままで、X で状況を確認してから、カラムの「確認したので再開する」か「設定 → X の自動化機能」で再開します。
>
> これらの機能は初期状態では動きません。X アカウントを追加したときなどに表示する確認画面で「リスクを理解して使う」を選んだときだけ有効になり、「設定 → X の自動化機能」でいつでも変更できます。使わない場合も、X カラムで X のページを見ることはできます（自動更新はしません）。

> 個人利用を想定した非公式クライアントです。X や Bluesky 側の仕様変更で動かなくなることがあります。

## 📥 インストール

[GitHub Releases](https://github.com/makorinaaa/SoCldeck/releases) から Windows 用インストーラー（`SocialDeck-<バージョン>-x64.exe`）をダウンロードして実行します。

インストーラーで入れたアプリは自動で更新されます。起動10秒後と、その後4時間ごとに新しいバージョンを確認してダウンロードし、通知から再起動するか、アプリの終了時に適用します。

## 📖 使い方

### はじめに：アカウントを追加する

起動するとログイン画面が開きます。

- **X**：表示名（任意・アカウントを見分けるための名前）を入れて「Xアカウントを追加」を押し、表示された X の画面でログインします
- **Bluesky**：ハンドルと**アプリパスワード**を入れて「Bluesky でログイン」を押します。アプリパスワードは [bsky.app の設定](https://bsky.app/settings/app-passwords) で発行できます（普段のパスワードは使いません）

追加したら「開く →」でメイン画面へ進みます。アカウントは後から「設定」→「アカウント」で追加・ログアウトできます。

### カラム

画面は「カラム」を横に並べて使います。サイドバーの「＋」やメニューの「カラムを追加」から追加します。

| サービス | 追加できるカラム |
|---|---|
| X | ホーム、ホーム（ネイティブ）、通知、通知（ネイティブ）、検索、リスト、設定 |
| Bluesky | タイムライン、通知、検索、Discover フィード、プロフィール、投稿ページ、設定 |
| 情報 | 本日のアニメ（AniList の放送・配信予定を日本時間 0:00〜27:00 で表示） |

- カラムはドラッグで並べ替え、端をドラッグで幅を変更、折りたたみもできます
- ヘッダーの「⋯」から、更新間隔・文字サイズの変更や削除ができます
- 削除しても、画面左下の「元に戻す」で直前の1件を元の位置に戻せます（アプリ起動中のみ）
- 更新に失敗したカラムには原因と「再試行」ボタンが表示されます

### X ホーム（ネイティブ）

X のホームを、Bluesky と同じアプリ独自の画面で表示するカラムです。

- 「X の自動化機能」を使う設定のときだけ表示します。X の規約に反する可能性がある機能です（冒頭の注意を参照）
- アプリが画面外で開いている X のページが受け取ったタイムラインを読み取って表示します（X の API は使いません）。いいね・リポスト・返信・削除も、その X のページのボタンをスクリプトで押して行います
- 「おすすめ」「フォロー中」をカラム上部で切り替えられます。X が選んだタブを覚えるので、再起動後も同じタブで開きます。フォロー中は「最新順」で表示します
- 他の人へのリプライはタイムラインに表示しません（自分の投稿へのスレッドと、自分宛てのリプライは表示します）。会話は詳細画面で読めます
- ポストをクリックすると、前後の会話と返信を Bluesky と同じ詳細画面で表示します。通知センターの X 通知（いいね・リポストを含む）も同じ画面で開きます
- 返信・引用は、そのカラムのアカウントで X の投稿画面から送ります。自分のポストは右下の「⋯」から削除できます
- 自動更新は1分ごとで、X のホームボタンを押したときと同じ軽い取得です。更新ボタンを押すとページを読み込み直し、他で削除されたポストも外れます
- 下の方を読んでいる間に届いた新着は、ヘッダーに「+N」で表示します。クリックで先頭へ移動します
- ログインしていないアカウントは、カラム内の「X にログイン」からログインできます

X 側の画面やデータの形が変わると、表示や操作ができなくなることがあります。その場合は通常の「ホーム」カラムを使ってください。

### X 通知（ネイティブ）

X の通知を、アプリ独自の画面で表示するカラムです。カラムの中で X のページを動かさないので、通常の「通知」カラムより軽く動きます。「X の自動化機能」を使う設定のときだけ表示します（冒頭の注意を参照）。

- 返信・メンション・引用はポストとして表示し、そのまま返信・いいね・リポストできます。いいね・リポスト・フォローは1行の通知で表示します
- 通知をクリックすると、対象のポストを詳細画面で開きます。フォロー通知はプロフィールをブラウザで開きます
- 通知は、通知センターと共有する画面外の X 通知ページから読み取ります。更新は X の通知タブを押したときと同じ軽い取得で、ページ全体は読み込み直しません
- 通知センターの「〇〇 の通知カラム」は、このカラムがあればこちらへ移動し、なければこのカラムを追加します

X が通知データを送らない場合は表示できません。その場合は通常の「通知」カラムを使ってください。

### 投稿

サイドバーの X / Bluesky の投稿ボタンから投稿画面を開きます。X への投稿・同時投稿は、X の投稿欄をスクリプトで操作して送るため、「X の自動化機能」を使う設定のときだけ使えます（冒頭の注意を参照）。

- 画像（最大4枚・ALT 付き）または動画1本を添付できます。動画は投稿前にトリミングできます
- 「Xにも投稿」「Blueskyにも投稿」で両方へ同時に投稿できます（返信を除く）。再試行では、成功した投稿先を除いて送り直します
- 書きかけの本文と返信先はアカウントごとに自動保存され、再起動しても戻ります。添付ファイルは保存されないので、再起動後は選び直してください
- X のアカウントは、分かり次第、追加時の表示名ではなく実際の @ユーザー名 で表示します
- `Ctrl+Enter` で送信、プレビューで投稿前の見た目を確認できます

### 通知

- **通知センター**：X と Bluesky の通知をまとめて表示します。サービス・種類・未読・会話（返信・メンション・引用）で絞り込めます
- **デスクトップ通知**：「設定」→「デスクトップ通知」で有効にします。サービス、通知の種類、特定のユーザー・キーワード、「SocialDeck を操作していない時だけ」で絞り込めます。クリックすると対象の投稿やプロフィールを開きます（X の投稿は通知センターと同じ詳細画面で開きます）。有効にした時点より前の通知はまとめて表示しません
- X の通知は、「X の自動化機能」を使う設定のときだけ、X が受け取る通知データから読み取ります。X ホーム（ネイティブ）カラムがあるアカウントは、X の未読バッジに変化があったときだけ通知ページを開いて取得します
- それ以外のアカウントや、X 通知（ネイティブ）カラムがあるアカウントは、画面外の通知ページを開いたままにし、X の通知タブを押して更新します（毎回ページを作り直しません）

### キーボードショートカット

`?` を押すと、アプリ内でも一覧を表示できます。

| キー | 動作 |
|---|---|
| `j` / `k` | 次 / 前の投稿へ移動 |
| `←` / `→` | 隣のカラムへ移動（投稿を選択中） |
| `1`〜`9` | N 番目のカラムへ移動 |
| `l` / `t` / `r` | いいね / リポスト / 返信（Bluesky） |
| `o` / `Enter` | 投稿を開く |
| `n` | 新規投稿（選択中のカラムのサービスで） |
| `Esc` | 選択を解除・画面を閉じる |
| `Ctrl+N` | カラムを追加 |
| `Ctrl+R` | すべて更新 |
| `Ctrl+Enter` | 投稿を送信 |

1文字のショートカットは、文字の入力中や設定画面などを開いている間は反応しません。X のカラムを選択している間は、X 自体のショートカットが使えます。

### 設定

サイドバーの「設定」から開きます。

- **外観・表示密度**：テーマ、アクセントカラー、表示密度（コンパクト／標準／ゆったり）。保存前にプレビューできます
- **ミュート**：表示しないキーワードとユーザー
- **メモリ管理**：使用量の確認と自動整理
- **バックアップと復元**：カラム配置や各種設定を JSON ファイルに書き出し・読み込みできます。ログイン情報・下書き・添付ファイル・通知履歴は含まれません。別の PC で復元するときは、先に同じアカウントを追加してください（X は表示名で照合します）。復元直前の状態は自動で退避され、「前回の復元直前に戻す」で戻せます

メニューからは、画面の拡大・縮小、全画面表示、**デスクトップウィジェット**（1つのカラムを透過・最前面で表示）も使えます。

## 🔐 セキュリティとプライバシー

- **Bluesky**：アプリパスワードはログインにだけ使い、保存しません。ログイン後のセッション情報は OS の暗号化機能（Electron `safeStorage`）で暗号化して保存します
- **X**：ログイン状態はアカウントごとに分けて保存し、Cookie は OS の暗号化キーで暗号化します。X の認証 Cookie の中身はアプリの画面側には渡しません
- **ログアウト**：X のアカウントを削除すると、そのアカウントの Cookie・保存データ・キャッシュを消去します
- **アプリの保護**：画面とシステムを分離（`contextIsolation`・`sandbox`）し、アプリ内部の操作は自アプリの画面からの要求だけを受け付けます

暗号化は「他の PC にデータを持ち出されても読めない」ための仕組みです。同じ OS アカウントにログインしている人や、そのアカウントで動くマルウェアからは保護できません。PC を共有する場合は OS のアカウントを分けてください。

詳しい方針は [SECURITY.md](SECURITY.md) を参照してください。

## 🛠️ 開発者向け

### 準備と起動

[Node.js](https://nodejs.org/) v22 以上が必要です。動作確認と CI は Windows で行っています。

```bash
npm install
```

```bash
npm start
```

`npm run dev` で開発者ツール付きで起動します。どちらも起動前に、動画処理用の FFmpeg を自動で取得・検証します（Windows）。

### テスト

| コマンド | 内容 |
|---|---|
| `npm run lint` | ESLint による静的チェック |
| `npm test` | 単体テスト |
| `npm run test:e2e` | 隔離した Electron 環境での画面操作テスト |
| `npm run test:all` | 単体テスト + E2E |
| `npm run test:security` | ローカルの疑似サーバーを使ったセキュリティテスト |
| `npm run security:check` | 秘密情報の混入チェック |

PR と main への push では、GitHub Actions で lint・単体テスト・E2E・セキュリティテストを実行します。

### ビルドとリリース

```bash
npm run build-win
```

成果物は `dist/` に作られます。`build-mac` / `build-linux` もありますが、CI では検証していません。リリース手順は [RELEASE.md](RELEASE.md) を参照してください。
